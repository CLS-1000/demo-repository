# Welcome to your organization's demo respository
This code repository (or "repo") is designed to demonstrate the best GitHub has to offer with the least amount of noise.

The repo includes an `index.html` file (so it can render a web page), two GitHub Actions workflows, and a CSS stylesheet dependency.

## SWITCHBOARD logo family

`index.html` is a gallery of the SWITCHBOARD brand boards: the CLS foundation mark, the five project logos, their sacred-geometry variations, animated intros, The Sentinel finale and a repo-data card. Each board is a standalone 1280×640 page in `brand/`, sharing the tokens in `brand/brand.css`.

The accent color defaults to signal orange (`#F26A1B`). Use the swatches in the gallery to switch it, or add `?accent=<hex>` to any board page, e.g. `brand/switchboard.html?accent=3FB6A8`.
